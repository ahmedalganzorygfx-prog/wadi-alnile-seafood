# موقع مطاعم أسماك وادي النيل — الواجهة الأصلية مع Python

هذه النسخة تستخدم ملف HTML الأصلي كواجهة أمامية حتى تحافظ على شكل الصفحة والألوان والتخطيط كما هي، بدلاً من إعادة رسمها بعناصر Streamlit مختلفة. تم استبدال صور المنتجات الوهمية بصور PNG محلية داخل `static/assets`.

## التشغيل على Windows
1. ثبّت Python 3.10 أو أحدث.
2. فك ضغط المجلد.
3. افتح Command Prompt داخل مجلد المشروع ونفّذ:

```bash
py -m pip install -r requirements.txt
py app.py
```

4. افتح `http://127.0.0.1:5000` في المتصفح.

## الوظائف
- بحث مباشر وتصنيفات أفقية.
- بطاقات المنتجات وزر الإضافة للسلة.
- سلة منفصلة للكمبيوتر والهاتف مع تعديل الكميات.
- إرسال الطلب عبر واتساب إلى الرقم المهيأ في الواجهة.
- حفظ نسخة من الطلبات في قاعدة SQLite محلية باسم `wadi_nile.db`.
- صور المنتجات محلية حتى لا تعتمد على مواقع صور خارجية.

## ملاحظات قبل النشر
- الصور المرفقة صور توضيحية وليست صورًا رسمية للمطعم.
- راجع الأسعار والعناوين ومواعيد العمل والرقم قبل النشر.
- هذه نسخة تشغيل محلي؛ النشر على الإنترنت يحتاج استضافة مناسبة وإعدادات أمان وتشغيل إنتاجية.

# مطاعم أسماك وادي النيل

تطبيق Streamlit عربي لإدارة قائمة الطعام والطلبات والفروع والعروض والتقييمات والشكاوى.

## التشغيل محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

## لوحة الإدارة

من داخل الموقع اختر «إدارة المطعم». كلمة المرور الافتراضية للتشغيل المحلي هي `change-this-password`.
غيّرها قبل الاستخدام الفعلي بتعيين متغير البيئة `ADMIN_PASSWORD`.

## التخزين

يحفظ التطبيق الطلبات والتقييمات والإعدادات في ملف `wadi_alnile.db` بجانب `app.py`.
على استضافات سحابية قد يكون نظام الملفات مؤقتًا؛ يلزم استخدام قاعدة بيانات مستضافة إذا أردت ضمان بقاء البيانات بعد إعادة النشر أو إعادة إنشاء التطبيق.

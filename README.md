# مطاعم أسماك وادي النيل

موقع عربي لإدارة قائمة الطعام والطلبات باستخدام Streamlit وPostgreSQL.

## المميزات

- واجهة عربية تدعم RTL.
- قائمة أصناف مصنفة مع الصور والأسعار.
- سلة مشتريات وتسجيل طلبات.
- حساب رسوم التوصيل والإجمالي.
- حفظ الطلبات في قاعدة بيانات PostgreSQL.
- إرسال تفاصيل الطلب عبر WhatsApp.
- لوحة إدارة محمية بكلمة مرور.
- إدارة الأصناف والأسعار والصور.
- متابعة الطلبات وتحديث حالاتها.
- تصدير الطلبات إلى CSV متوافق مع Excel.
- إعدادات المطعم والتواصل والتوصيل.

## التشغيل

1. ثبّت Python 3.11 أو إصدارًا متوافقًا.
2. ثبّت الحزم:

   pip install -r requirements.txt

3. أنشئ قاعدة بيانات PostgreSQL على Supabase.
4. اضبط DATABASE_URL وADMIN_PASSWORD.
5. شغّل التطبيق:

   streamlit run app.py

## النشر

ارفع الملفات إلى GitHub، ثم اربط المستودع بـ Streamlit Community Cloud.

أضف DATABASE_URL وADMIN_PASSWORD في قسم Secrets داخل إعدادات التطبيق.

لا ترفع كلمات المرور أو بيانات الاتصال السرية إلى GitHub.

# موقع أسماك وادي النيل - Python / Streamlit

## التشغيل على Windows
1. ثبّت Python 3.10 أو أحدث.
2. ضع `app.py` و`requirements.txt` في مجلد واحد.
3. افتح CMD داخل المجلد ونفّذ:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. سيفتح الموقع في المتصفح تلقائيًا.

## المزايا
- تصميم عربي RTL متجاوب قريب من ملف HTML المرفق.
- تصنيفات المنتجات والبحث.
- سلة مشتريات وتعديل الكميات وحساب الإجمالي.
- بيانات العميل والفرع وإعداد رسالة واتساب.
- تسجيل الطلبات والمنتجات في قاعدة SQLite محلية `wadi_nile.db`.
- لوحة إدارة لإضافة وتعديل المنتجات ومتابعة الطلبات.

## دخول لوحة الإدارة
كلمة المرور الافتراضية للتجربة: `admin123`
غيّرها قبل نشر الموقع:
- Windows CMD: `set WADI_ADMIN_PASSWORD=كلمة_مرور_قوية`
- أو إعدادات Streamlit Secrets: `ADMIN_PASSWORD = "كلمة_مرور_قوية"`

## تنبيهات مهمة
- المنتجات والأسعار والصور الأولية أمثلة مأخوذة من نموذج HTML، ويجب مراجعتها مع المطعم قبل الاستخدام الفعلي.
- صور `placehold.co` صور مؤقتة؛ يمكنك وضع روابط صور الوجبات الحقيقية من لوحة الإدارة.
- عند تأكيد الطلب، يتم حفظه في قاعدة البيانات ثم يظهر رابط لفتح واتساب. العميل يحتاج إلى الضغط على الرابط لإرسال الرسالة بنفسه.
- هذه نسخة أولية تعمل محليًا. لنشرها على الإنترنت تحتاج استضافة، HTTPS، نسخًا احتياطيًا لقاعدة البيانات، وكلمة مرور إدارة قوية.
